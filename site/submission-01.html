Claude Code와 PPT 스킬
실습 결과를 제출합니다.

작업 폴더에서 만든 스킬과 실제 적용 결과를 함께 남깁니다. 파일 하나만 내고 끝내지 말고, 스킬이 새 요청에서도 기준을 지키는지 보여주세요.

필수 산출물
  • 스킬 폴더 — SKILL.md와 필요하면 분리한 레퍼런스·스크립트
  • PPT 결과물 — 스킬로 만든 발표자료 파일
  • 실행 근거 — 스킬 호출과 결과 확인을 보여주는 텍스트·스크린샷
확인할 것

호출 조건, 작업 순서, 검증 항목이 짧고 구체적인가

제출 방법

파일을 여러 개 고르거나 스킬 폴더를 그대로 선택합니다.

주의

API 키·토큰·개인정보가 담긴 설정 파일은 빼고 제출합니다.

완료 기준
  1. 내 업무에 맞는 스킬 1개가 있다.
  2. 다른 주제로 다시 실행한 PPT 결과물이 있다.
  3. 결과를 보고 스킬 기준을 한 번 이상 보완했다.
업로드 접수 준비 중

파일·폴더 접수와 코치 전용 검토 화면은 구현 중입니다. 운영 서버 주소를 연결하면 이 자리에서 바로 제출할 수 있습니다.
