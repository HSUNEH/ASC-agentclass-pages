LESSON 03 · 3-3

연결했다는 말보다
실제 데이터를 확인합니다.

설치 메시지가 보였다고 끝난 것이 아닙니다. 가장 작은 읽기 작업으로 연결 범위와 실제 결과를 확인합니다.

이번 레슨이 끝나면권한 범위를 점검하고, 외부 데이터 한 건을 읽어 실제 화면과 비교합니다.

읽기 → 확인 → 제한된 쓰기 순서입니다.

처음부터 메시지를 보내거나 데이터를 바꾸지 않습니다. 먼저 읽기 전용 작업으로 어떤 도구와 데이터에 접근할 수 있는지 확인합니다.

공식 안내

서버의 설치 방식과 인증 방법을 확인합니다.

권한 범위

읽기 전용인지, 쓰기·전송 권한까지 있는지 확인합니다.

실제 비교

Claude Code 결과가 외부 서비스 화면과 맞는지 봅니다.

연결 검증은 네 단계입니다.

  • 테스트 공간을 정합니다.운영 채널이나 중요한 문서에서 바로 시작하지 않습니다.
  • 연결 상태를 봅니다.등록된 도구와 접근 범위를 확인합니다.
  • 작은 읽기를 실행합니다.최근 문서 제목처럼 변경이 없는 요청부터 합니다.

직접 해봅니다.

연결된 Notion 도구를 사용해서
내가 최근에 만든 페이지 3개의 제목만 알려줘.
페이지 내용은 수정하지 마.
조회한 공간과 사용한 도구도 함께 알려줘.

Notion 화면에서 실제 제목과 접근한 공간이 맞는지 직접 비교합니다. 일치하기 전에는 쓰기 작업으로 넘어가지 않습니다.

다음에도 이렇게 판단합니다.

여기까지“연결됨” 표시는 시작일 뿐입니다. 실제 외부 데이터와 결과가 맞을 때 연결이 검증됩니다.

원본 강의의 핵심을 더 봅니다.

연결 성공과 업무 성공은 다릅니다.

원본 3강은 설치 뒤 실제 데이터 하나를 읽어 보며 권한·연결·형식을 확인합니다. 목록에 MCP가 보인다는 사실만으로는 원하는 서비스에서 결과를 가져왔는지 알 수 없습니다.

지금도 통하는 운영 원칙입니다.

관찰 가능한 결과를 남깁니다.

도구 호출 로그만 보지 말고, 읽어 온 문서 제목·생성한 초안·저장된 링크처럼 사람이 바로 확인할 수 있는 결과를 남깁니다. 문제가 생기면 어느 단계가 실패했는지도 드러납니다.
