ASC 에이전트트랙이 강의 목차
LESSON 01 · 1-1

대화창의 답이 아니라
폴더의 결과를 만듭니다.

Claude Code는 내가 연 작업 폴더에서 파일을 읽고, 만들고, 고치며 일을 끝냅니다.

이번 레슨이 끝나면작업 폴더에서 작은 파일을 만들고 직접 확인합니다.

웹 챗과 무엇이 다를까요?

대화는 아이디어를 얻는 데 좋습니다. 하지만 실제 파일과 명령, 프로젝트 문맥을 다루려면 작업 폴더가 필요합니다.

웹 챗

답을 받고 내가 다음 행동을 이어갑니다.

Claude Code

폴더 안의 자료를 바탕으로 파일과 실행 결과를 남깁니다.

처음에는 이렇게 시작합니다.

  • 빈 연습 폴더를 만듭니다.낯선 프로젝트보다 직접 만든 빈 폴더가 안전합니다.
  • 폴더를 신뢰할지 확인합니다.받은 프로젝트라면 승인 전에 설정과 명령을 먼저 봅니다.
  • 작은 파일 하나를 만듭니다.처음부터 큰 작업을 맡기지 말고 결과가 보이는 요청부터 합니다.

직접 해봅니다.

이 폴더에 hello.md 파일을 만들고,
첫 줄에 "ASC 에이전트 트랙을 시작합니다"라고 적어줘.
만든 뒤 파일 내용을 다시 보여줘.

대화창의 답보다 Finder나 편집기에서 hello.md가 실제로 생겼는지 확인합니다.

다음에도 이렇게 판단합니다.

여기까지이후 모든 실습도 같습니다. 요청 → 폴더의 결과 확인 → 다음 작업 순서로 진행합니다.

원본 강의의 핵심을 더 봅니다.

에이전트는 답만 만들지 않습니다.

원본 1강은 AI 코딩 에이전트를 계획 수립 → 파일 탐색 → 도구 실행 → 결과 확인까지 실제 행동하는 AI로 설명합니다. 그래서 첫 요청도 “무엇을 만들까”보다 “어떤 결과를 어디에서 확인할까”를 함께 정해야 합니다.

지금도 통하는 운영 원칙입니다.

단순한 한 번의 실행부터 시작합니다.

Anthropic은 복잡한 프레임워크보다 단순하고 조합 가능한 패턴을 먼저 권합니다. 한 번 실행하고 파일·화면·테스트 결과를 확인한 뒤에만 다음 단계를 붙입니다.
