읽은 결과를
안전하게 공유합니다.

원본 3강의 핵심 흐름입니다. Notion에서 읽고, 필요한 내용만 정리한 뒤, Slack 테스트 채널에 공유합니다.

이번 레슨이 끝나면초안을 먼저 확인하고, 테스트 채널에서 실제 전송 결과를 확인합니다.

외부 쓰기는 한 단계 더 확인합니다.

읽기는 정보 확인입니다. 전송은 다른 사람의 업무 환경을 바꾸는 행동입니다. 그래서 대상·내용·채널을 확인할 수 있는 초안 단계를 둡니다.

조회

필요한 Notion 문서만 읽습니다.

정리

제목, 한 줄 요약, 원문 링크처럼 필요한 정보만 남깁니다.

초안 확인

전송 전에 사람이 내용과 채널을 확인합니다.

테스트 전송

운영 채널보다 테스트 채널에서 먼저 확인합니다.

공유는 두 번에 나눕니다.

  • 초안을 먼저 받습니다.바로 전송하지 말고 메시지 형식을 봅니다.
  • 대상 채널을 확인합니다.테스트 채널인지, 링크와 제목이 맞는지 확인합니다.
  • 전송 뒤 결과를 확인합니다.외부 서비스에 남은 메시지와 링크를 다시 봅니다.

직접 해봅니다.

Notion에서 최근에 만든 페이지 3개를 찾아줘.
각 페이지의 제목, 한 줄 요약, 링크를 정리해.
# mcp-test 채널에 보내기 전에 메시지 초안을 먼저 보여줘.

초안을 승인한 다음에만 테스트 채널로 보냅니다. 전송 뒤에는 메시지 링크와 채널 이름을 다시 확인합니다.

다음에도 이렇게 판단합니다.

여기까지자동화는 빠른 전송보다, 잘못된 대상에 잘못된 내용을 보내지 않는 구조가 먼저입니다.

원본 강의의 핵심을 더 봅니다.

외부 쓰기는 초안부터 시작합니다.

원본 3강의 Notion·Slack 예시는 자료를 모으고, 요약한 뒤, 테스트 채널에서 공유하는 흐름입니다. 실제 채널에 바로 보내기보다 초안과 대상 채널을 사람이 확인하는 단계가 필요합니다.

지금도 통하는 운영 원칙입니다.

권한은 최소 범위로 시작합니다.

연결할 때는 필요한 서비스와 범위만 승인합니다. 자동화 편의를 위해 광범위한 쓰기 권한을 주지 말고, 업무가 안정된 뒤에도 주기적으로 연결과 권한을 점검합니다.
