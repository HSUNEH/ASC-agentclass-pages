LESSON 03 · 제출

MCP 자동화 하나를
검증 가능한 형태로 냅니다.

연결한 도구 수가 아니라, 실제 업무의 입력·처리·출력이 안전하게 이어지는지가 기준입니다. 외부 쓰기는 반드시 테스트 공간과 확인 지점을 남깁니다.

필수 산출물
  • 자동화 시나리오 — 업무 목적, 입력, 처리, 출력, 승인 지점
  • 연결·실행 근거 — MCP 설정 일부, 실행 로그 또는 스크린샷
  • 외부 결과 — Notion 페이지·Slack 테스트 메시지 등 실제 결과 증거
확인할 것

읽기와 쓰기 권한, 테스트 대상, 사람 확인 지점이 분명한가

제출 방법

문서·스크린샷·설정 예시를 고르거나 자동화 폴더를 선택합니다.

주의

토큰·웹훅 URL·개인정보는 반드시 지우거나 가립니다.

완료 기준
  1. 자동화할 업무 하나와 입력·처리·출력이 정리돼 있다.
  2. 필요한 MCP만 연결해 테스트 공간에서 한 번 실행했다.
  3. 외부 서비스에 남은 결과와 다음 보완점이 있다.
업로드 접수 준비 중

파일·폴더 접수와 코치 전용 검토 화면은 구현 중입니다. 운영 서버 주소를 연결하면 이 자리에서 바로 제출할 수 있습니다.
