LESSON 04

4강 · 플러그인과 예약 태스크로
완전 자동화

잘된 업무 방식을 플러그인으로 묶고, 검증한 자동화를 예약 태스크로 반복 실행합니다.

이 강의에서 남길 것

내 업무용 플러그인 1개, Scheduled Task 1개, 실행 결과와 개선 기록

4-1플러그인은 왜 필요한가

스킬·명령어·커넥터·에이전트를 하나의 업무 패키지로 묶기

4-2플러그인을 안전하게 설치하고 쓴다

검증된 출처, 권한 확인, 작은 작업으로 테스트하기

4-3내 업무용 플러그인을 만든다

반복 업무의 기준과 명령어를 내 방식으로 설계하기

4-4예약 태스크로 반복 실행을 만든다

Run Now로 검증한 뒤 일정에 맞춰 자동화하기

4-5자동화를 안전하게 운영한다

프롬프트·권한·사람 확인 지점으로 신뢰 쌓기

과제 제출플러그인과 예약 태스크 만들기

실행 결과, 스크린샷, 개선 기록 제출하기
