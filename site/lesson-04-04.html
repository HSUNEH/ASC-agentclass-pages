매번 요청하던 일을
정해진 시간에 실행합니다.

Scheduled Task는 Cowork에서 반복 업무를 예약하는 기능입니다. 비개발자는 GUI에서 시작하고, 실행 전에 Run Now로 먼저 확인합니다.

이번 레슨이 끝나면내 업무에 맞는 예약 태스크 하나를 설계하고 즉시 테스트합니다.

자동화 방식은 목적이 다릅니다.

수동 실행

직접 요청할 때마다 실행합니다. 결과를 익히는 첫 단계입니다.

반복 실행

CLI /loop는 짧은 상태 확인처럼 빠른 반복에 맞습니다.

예약 실행

Scheduled Task는 매일·평일·매주 정해진 시간에 장기 자동화를 시작하기 좋습니다.

예약은 이 순서로 만듭니다.

  • 결과 하나를 정합니다.모닝 브리핑, 주간 리포트처럼 실행 뒤 확인할 결과를 분명히 합니다.
  • 이름·프롬프트·빈도를 입력합니다.Daily, Weekdays, Weekly 중 업무 주기에 맞게 고릅니다.
  • Run Now로 바로 테스트합니다.예약을 켜기 전에 연결·권한·출력 형식을 확인합니다.
  • 결과를 보고 프롬프트를 고칩니다.첫 결과가 부족하면 조건과 형식을 더 구체적으로 적습니다.

작은 모닝 브리핑부터 시작합니다.

오늘의 모닝 브리핑을 만들어줘.
1. 최근 12시간 중요 이메일 요약
2. 오늘 일정과 준비 사항
3. 내가 해야 할 우선순위 TOP 3
각 항목을 짧은 bullet point로 정리해줘.
답장 초안은 만들되, 보내지는 마.

입력 범위, 출력 형식, 사람이 확인할 지점을 함께 적으면 자동화가 훨씬 안전해집니다.
