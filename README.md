# ASC-agentclass-pages

ASC 에이전트트랙의 공개 학습 리더입니다.

## 구조

- `site/index.html`: 과정 소개와 1~4강·강의별 과제 진입 카드를 두는 랜딩 페이지
- `site/lesson-01.html` ~ `site/lesson-04.html`: 강의 목표와 세부 레슨 목차
- `site/lesson-01-01.html` 등 세부 레슨 페이지: 한 화면에 핵심 하나씩 보여주는 단계형 리더
  - 1강: 1-1 ~ 1-4 — Claude Code 기초와 PPT 스킬 자동화
  - 2강: 2-1 ~ 2-4 — 멀티에이전트와 검증 가능한 워크플로
  - 3강: 3-1 ~ 3-5 — MCP를 활용한 더욱 강력한 자동화
  - 4강: 4-1 ~ 4-5 — 플러그인과 예약 태스크로 완전 자동화
- 각 강의는 첫 세부 레슨의 사전 진단과 마지막 세부 레슨의 후속 테스트를 제공합니다.
- `site/submission-01.html` ~ `site/submission-04.html`: 강의별 제출물·완료 기준·보안 주의사항을 안내합니다. 각 강의의 마지막 레슨은 해당 페이지로 이어집니다.
- `site/lesson.css`, `site/lesson.js`: 공통 단계 전환, 진행률, 키보드 이동, 테스트 피드백을 제공합니다.

원본 영상의 사례와 실습 흐름을 참고하되, 현재 도구 동작과 교육 설명은 최신 Anthropic Engineering의 단순한 워크플로 우선, 점진적 정보 공개, 맥락 관리, 실행 검증 원칙에 맞춰 다시 구성합니다.

실행 산출물 제출과 코치 피드백은 ASC 교육 플랫폼에서 진행합니다.
