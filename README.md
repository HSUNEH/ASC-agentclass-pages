# ASC-agentclass-pages

ASC 에이전트트랙의 공개 리더입니다.

## 구조

- `site/index.html`: 과정 소개와 1~3강 진입 카드만 두는 랜딩 페이지
- `site/lesson-01.html` ~ `site/lesson-03.html`: 한 화면에 핵심 하나씩 보여주는 단계형 레슨
- 각 레슨은 사전 테스트 → 핵심 흐름 → 후속 테스트 순서로 구성합니다.
  - 사전 테스트: 학습 전에 큰 가지를 점검해 학습 목적을 분명히 합니다.
  - 후속 테스트: 핵심 개념 1문항과 세부 기준 1문항으로 이해를 확인합니다.
- `site/lesson.css`, `site/lesson.js`: 공통 단계 전환, 진행률, 키보드 이동, 테스트 피드백을 제공합니다.

실행 산출물 제출과 코치 피드백은 ASC 교육 플랫폼에서 진행합니다.
